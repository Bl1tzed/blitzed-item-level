# Blitzed Item Level

A lightweight World of Warcraft addon that shows the **equipped item level**
above the weapon slots — on your own character and on inspected players.

## Features

- `ILVL: 285.00` label above the weapon slots on the character frame.
- The same label on the inspect frame when examining other players.

## Installation

1. Copy the `Blitzed Item Level` folder into:
   `World of Warcraft/_retail_/Interface/AddOns/`
2. Restart WoW (or `/reload` if already running).
3. Make sure the addon is enabled in the AddOns list at character select.

## Usage

- Open your character frame (default `C`) — the item level appears above your
  weapons.
- Right-click another player and choose **Inspect** to see their item level.
- Type `/bil` or `/blitzeditemlevel` in chat for a quick readout.
